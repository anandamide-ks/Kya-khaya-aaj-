# Kya Khaya Aaj?

A calorie tracker with Mr Idli and Ms Chutney. anandamide.ks

- 1,092 foods from Indian regional and world cuisines, each with a picture
- Add your own foods, with your own photo
- Works offline and installs on a phone like an app
- Everything is saved on the device. Use **Save a backup** in the app to move it to another phone.

## Put it online with GitHub Pages

1. On github.com (account `anandamide-ks`), create a new public repository named `kya-khaya-aaj`.
2. Click **uploading an existing file**, drag in every file from this folder, and commit.
3. Go to **Settings → Pages**, set the source to **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
4. After a minute the app is live at `https://anandamide-ks.github.io/kya-khaya-aaj/`.

## Install it on a phone

- **Android (Chrome):** open the link and tap **Install** in the app, or use the menu → **Add to Home screen**.
- **iPhone (Safari):** open the link, tap **Share**, then **Add to Home Screen**.

## Updating later

Replace the changed files in the repository, then open `sw.js` and change `VERSION` (for example `kka-v1` to `kka-v2`) so phones fetch the new copy.

Food values are estimates for typical servings, not lab measurements.
